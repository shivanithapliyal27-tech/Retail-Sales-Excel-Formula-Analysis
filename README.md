# Retail Sales Excel Formula Analysis

## 📊 Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel. 
The project demonstrates the practical use of Excel formulas and functions for data analysis, lookup, conditional analysis, and summary calculations.

## 🎯 Objective

The main objective of this project is to understand and apply commonly used Excel formulas and functions to analyze retail sales data efficiently.

## 📁 Dataset

The dataset contains retail sales information with the following columns:

- Order ID
- Date
- Product
- Quantity
- Unit Price
- Total Sales
- Region
- Salesperson

## 🧮 Excel Functions Used

The following Excel formulas and functions were used in this project:

- XLOOKUP
- VLOOKUP
- IF
- SUMIFS
- COUNTIFS
- LEFT
- RIGHT
- LEN

## 📌 Analysis Performed

### Key Performance Indicators (KPIs)

- Total Sales
- Total Quantity Sold
- Average Sales
- Total Orders

### Regional Analysis

Sales and order counts were analyzed for different regions using:

- SUMIFS
- COUNTIFS
- AVERAGEIFS

### Product Analysis

Product-level information was analyzed using lookup functions such as:

- XLOOKUP
- VLOOKUP

### Conditional Analysis

The IF function was used to classify sales values into categories such as:

- High
- Low

### Text Analysis

Text functions were used to extract and analyze product names:

- LEFT
- RIGHT
- LEN
